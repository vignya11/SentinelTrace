# Sample forensic report (SYNTHETIC)

A real PDF generated by the application from the **synthetic demo dataset** is included: `docs/sample_case_report_SYNTHETIC.pdf`
(case "Synthetic: password guessing against demo.alice", 14 failed logins from 203.0.113.45 followed by a success).
It contains the manifest (export time, examiner, filters, record count, chain head sequence/hash), analyst notes, the event table and the evidence-handling note.
To reproduce: seed the demo DB → sign in as `demo_investigator` → *Investigations → case → Export PDF report* → *Evidence & custody* shows the SHA-256 and custody log.
Wording rule used throughout: findings are **indicators requiring investigation**, never proof of compromise.
